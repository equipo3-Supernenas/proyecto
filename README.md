# Como usar este repo

Aqui estan unas pequeñas instrucciones para usar el repo, si no se cumplen ![Imagen para atemorizar](https://i.ibb.co/C3RJh46z/hqdefault.jpg)

**Orden de instrucciones**
-Primero antes de hacer nada hago un git pull
-Cuando haya hecho mis cambios hago git add . para añadir mis cambios
-Despues hago git commit -m "Y escribo entre comillas lo que voy a añadir"
-Hago otro git pull por si acaso
-Finalmente lanzo un git push

Cualquier duda, preguntasela al perrito programador
