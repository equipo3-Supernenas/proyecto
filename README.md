# Como usar este repo

Aqui estan unas pequeñas instrucciones para usar el repo, si no se cumplen ![Imagen para atemorizar](https://i.imgur.com/aVP4DKp.png)

## Orden de instrucciones

- Primero me clono el repo con ``git clone https://github.com/equipo3-Supernenas/proyecto.git``
- Despues creo una rama aparte con el comando ``git switch -c feature/nombre-de-tu-tarea``
- Cuando haya hecho mis cambios hago ``git add .``
- Despues hago ``git commit -m "Y escribo entre comillas lo que voy a añadir"``
- Siempre antes de subir algo haz ``git pull`` para bajar la ultima version del repo
- Si es la primera vez que has hecho tu rama, pones ``git push -u origin feature/nombre-de-tu-tarea``
- Si no es la primera vez que trabajas en tu rama usas ``git push``
- **¡ÚLTIMO PASO OBLIGATORIO!** Entra en la página de GitHub, dale al botón de **"pull request"** despues dale a **New pull request** selecciona `main` y tu ``rama`` despues dale a **Create pull request** y yo me encargare de revisar que todo este correcto para incorporarlo al ``main``

Cualquier duda, preguntasela al perrito programador
